# Changelog

## 0.1.0

First cut, lifted from the evaluation package of a document-intelligence
product where it ran for five months against construction plan sets and
specifications. The product kept what reads its database and its models;
this package is the part that needed neither: the position-swapped
head-to-head, the validated rubric parse, the parity loop over frozen
contexts, the structured-output parser, regression floors keyed on
(runtime, model), the set diff, the matrix report and the embedding A/B
scorer. The four write-ups in `docs/` are the experiments that shaped it.
